# CLAUDE.md에 지침 추가하기

사용자가 전달한 지침을 프로젝트의 `CLAUDE.md` 파일에 반영하는 작업이다.
추가하려는 지침: $ARGUMENTS

## 대상 파일
- **반드시** `CLAUDE.md` (프로젝트 루트의 `AGENTS.md`나 다른 파일이 아님) 를 대상으로 한다.

## 작업 절차

1. **대상 파일 읽기**
   - `CLAUDE.md` 전체를 읽어 현재 내용과 섹션 구조를 파악한다.

2. **중복 검사 (가장 중요)**
   - 전달받은 지침이 파일에 **이미 존재하는지** 확인한다.
   - 글자가 똑같은지가 아니라 **의미상 같은 내용**이 이미 있는지를 본다 (표현만 다르고 같은 규칙이면 중복으로 간주).
   - 이미 존재한다면 **절대 파일을 수정하지 말고**, 작업을 중단한 뒤 사용자에게 "이미 존재한다"고 알린다.
     - 어느 섹션의 어떤 문장과 중복되는지(`file_path:line` 또는 해당 문구 인용)를 함께 보여 준다.

3. **추가 (중복이 아닐 때만)**
   - 지침의 성격에 가장 잘 맞는 기존 섹션을 찾아 그 안에 추가한다.
     (예: 코드 스타일 관련 → `## 컨벤션`, 권한 관련 → `## 권한` 등)
   - 적절한 기존 섹션이 없으면 파일 맨 아래에 새 `##` 섹션을 만들어 추가한다.
   - 기존 문서의 **말투·서식·들여쓰기·불릿 스타일**을 그대로 따른다. 전달받은 지침이 구어체면 문서 톤에 맞게 다듬되, 의미는 바꾸지 않는다.
   - `Edit` 도구로 해당 위치에만 정확히 추가하고, 파일의 다른 부분은 건드리지 않는다.

4. **결과 보고**
   - 어느 섹션에 어떤 문장으로 추가했는지 사용자에게 간단히 알린다.

## 주의
- 사용자가 전달한 지침이 비어 있으면, 무엇을 추가할지 먼저 되묻는다.
- 중복일 때는 어떤 경우에도 파일을 수정하지 않는다.
