## 작업 순서
- **작업 분석:** 작업의 핵심 요구사항과 목표를 이해하기. 버그일경우 해당 문제가 실제로 발생하는지 확인하기.
- **의존성 분속:** 다른 작업이 선행돼야 하는 의존성 파악하기.
- **깃허브에 이슈를 생성할지 묻기:** 깃허브에 이 이슈를 공식적으로 생성할지 여부를 사용자가 결정하도록 요청하기.
